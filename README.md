# TicketManagementSystem

## Описание

TicketManagementSystem — веб-приложение для управления событиями и продажи электронных билетов.

Пользователь может зарегистрироваться, войти в систему, просмотреть каталог событий, добавить билеты в корзину, оформить заказ, оплатить его через Stripe Checkout или в тестовом режиме, получить электронный билет с QR-кодом и скачать его в PDF.

Администратор управляет пользователями, событиями, категориями, заказами, отчётами и журналом аудита, а также сканирует QR-коды для валидации билетов.
